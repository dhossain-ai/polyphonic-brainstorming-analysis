# Polyphonic Brainstorming Analysis

This repository contains an NLP homework project analyzing brainstorming dialogues using a simple polyphonic analysis approach.

## Project Goal

The goal is to compare three types of brainstorming sessions:

1. Human-human
2. Human-chatbot
3. Chatbot-chatbot

The analysis focuses on identifying different "voices" in the conversations, such as technical, human-centered, social, and ethical/legal perspectives. The project also examines convergences and divergences between these voices.

## Topic

The selected brainstorming topic is:

**Can a machine be creative?**

## Repository Structure

```text
chat_logs/
    Contains the collected brainstorming dialogue files.

code/
    Contains the Python program for polyphonic analysis.

results/
    Contains the output files generated by the Python program.

essay/
    Contains the final essay comparing the three brainstorming settings.
```
